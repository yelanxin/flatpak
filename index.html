OxiTide Flatpak repository

Official Flatpak remote for OxiTide, the Hi-Res TIDAL player for Linux.

Install

flatpak install --user https://flatpak.oxitide.com/oxitide.flatpakref

Updates arrive via flatpak update. The GNOME runtime is fetched from Flathub automatically.
